# NEXORA — Responsive Landing Page

## About

NEXORA is a modern and responsive landing page created as part of my Web Development Internship Task.

## Features

- Responsive navigation bar
- Modern hero section
- About section
- Services section
- Contact section
- Footer with social links
- CSS animations and hover effects
- Responsive design for desktop, tablet and mobile devices

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Animations

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the project using Live Server.
